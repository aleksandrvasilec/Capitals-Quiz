🗺️ Capitals Quiz — Multi‑Language Geography Trainer
8 languages, one interactive quiz – learn world capitals with hints, track your progress, and master geography!

✨ Features
🌍 Quiz mode – guess the capital of a randomly selected country

💡 Three hint levels –
1️⃣ First letter of the capital
2️⃣ Number of letters in the capital
3️⃣ Multiple choice (3 options)

📊 Score tracking – correct/incorrect count and percentage

🎯 All countries or by continent (optional)

💾 Persistent stats – saves your progress to a file

🖥️ Clean CLI interface with colors (where supported)

🚀 Quick Start
bash
# Start a quiz
<command> start

# Show your statistics
<command> stats

# Show available commands
<command> help

# Exit
<command> exit
During the quiz:

Type your answer and press Enter

Type hint to reveal the next hint (3 levels)

Type skip to move to the next country

Type quit to end the session
